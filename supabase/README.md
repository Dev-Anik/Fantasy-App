# Skippr লাইভ অ্যালার্ট: Supabase সেটআপ গাইড

এই ফোল্ডারে Skippr-এর লাইভ নোটিফিকেশন সার্ভারের সব কোড আছে। ম্যাচ চলার সময় কোনো প্লেয়ার মাঠে নামলে, গোল করলে বা কার্ড পেলে এই সার্ভার ইউজারের ফোনে নোটিফিকেশন পাঠায়।

## কী কী আছে

| ফাইল | কাজ |
|---|---|
| `migrations/..._live_alerts.sql` | Database-এর তিনটা টেবিল: ফোনের তালিকা, প্রতিটা দলের প্লেয়ার, আর Worker-এর স্মৃতি |
| `migrations/..._live_alerts_schedule.sql` | প্রতি মিনিটে Worker চালানোর সময়সূচি (pg_cron) |
| `functions/register` | অ্যাপ এখানে ফোনের পুশ টোকেন আর FPL টিম আইডি পাঠায় |
| `functions/live-worker` | ম্যাচের সময় FPL দেখে নোটিফিকেশন পাঠানোর মূল কর্মী |
| `functions/_shared/auth.ts` | কে ডাকছে সেটা যাচাই, আর Database-এ ঢোকার চাবি |
| `config.toml` | Supabase CLI-র সেটিংস |

নিরাপত্তা: টেবিলগুলোতে Row Level Security চালু আছে, কিন্তু কোনো policy নেই। তাই শুধু আমাদের দুটো function (secret key দিয়ে) টেবিলগুলো পড়তে বা বদলাতে পারে। অ্যাপের public key দিয়েও সরাসরি টেবিলে ঢোকা যায় না। পাসওয়ার্ড বা ইমেইল কখনো এখানে আসে না।

## ধাপ ১: Supabase প্রজেক্ট তৈরি

১. https://supabase.com এ গিয়ে ফ্রি অ্যাকাউন্ট খুলুন। GitHub দিয়ে সাইন আপ করা সবচেয়ে সহজ।
২. **New project** চাপুন:
   - **Name:** `skippr`
   - **Database password:** শক্ত একটা পাসওয়ার্ড দিন এবং কোথাও নিরাপদে লিখে রাখুন।
   - **Region:** ইউরোপের যেকোনো অঞ্চল। এই ক্রমে যেটা তালিকায় পাবেন: **West EU (Ireland)**, **Central EU (Frankfurt)**, **West EU (Paris)**। শুধু বড় এলাকা দেখালে **Europe** বাছুন। FPL-এর ডেটা যুক্তরাজ্য থেকে আসে, তাই কাছাকাছি থাকলে একটু দ্রুত হয়। তবে পার্থক্য খুবই সামান্য। প্রজেক্ট তৈরির পর অঞ্চল বদলানো যায় না।
৩. প্রজেক্ট তৈরি হতে ১-২ মিনিট লাগবে।
৪. **Project Settings → General** থেকে **Project ID** (Reference ID) কপি করুন। দেখতে অনেকটা `abcdefghijklmnop` এর মতো। নিচে একে `<project-ref>` বলা হয়েছে।

## ধাপ ২: আপনার কম্পিউটার থেকে প্রজেক্টে যুক্ত হওয়া

প্রজেক্টের মূল ফোল্ডারে (`H:\profpl`) টার্মিনাল খুলে চালান:

```bash
npx supabase login
npx supabase link --project-ref <project-ref>
```

`login` ব্রাউজার খুলে অনুমতি চাইবে। `link` ধাপ ১-এর Database password চাইবে।

## ধাপ ৩: Database তৈরি

```bash
npx supabase db push --remote
```

`--remote` অবশ্যই দেবেন। CLI-র নতুন সংস্করণে (v3) `db push` ডিফল্টভাবে কম্পিউটারের লোকাল Database-এ পাঠাতে চায়, যার জন্য Docker লাগে। `--remote` দিলে আসল প্রজেক্টে যায়। Database password চাইলে ধাপ ১-এর password দিন, আর নিশ্চিত হতে চাইলে `Y` দিন।

এটা দুটো migration চালাবে:
- তিনটা টেবিল তৈরি করবে।
- প্রতি মিনিটে Worker চালানোর সময়সূচি বসাবে।

## ধাপ ৪: Secret key তৈরি আর Vault-এ রাখা

Worker-কে ডাকার জন্য সময়সূচির একটা গোপন চাবি দরকার।

১. **Project Settings → API Keys** এ যান।
২. **Secret keys** অংশে **Create new secret key** চাপুন। নাম দিন `cron`। তৈরি হওয়া `sb_secret_...` চাবিটা কপি করুন।
৩. বাম দিকের মেনু থেকে **SQL Editor** খুলে এই দুই লাইন চালান। নিজের মান বসিয়ে নেবেন:

```sql
select vault.create_secret('https://<project-ref>.supabase.co', 'project_url');
select vault.create_secret('sb_secret_আপনার_চাবি', 'secret_key');
```

> ⚠️ এই secret key কখনো অ্যাপে, git-এ বা কাউকে পাঠাবেন না। এটা দিয়ে পুরো Database নিয়ন্ত্রণ করা যায়।

## ধাপ ৫: Function দুটো চালু (deploy) করা

```bash
npx supabase functions deploy register
npx supabase functions deploy live-worker
```

ঐচ্ছিক: Expo-তে পুশ নিরাপত্তা (Enhanced Push Security) চালু করলে Expo-র access token secret হিসেবে দিন:

```bash
npx supabase secrets set EXPO_ACCESS_TOKEN=আপনার_expo_token
```

## ধাপ ৬: পরীক্ষা করা

**ক) Worker নিজে ডেকে দেখা।** `sb_secret_...` চাবি বসিয়ে চালান:

```bash
curl -X POST "https://<project-ref>.supabase.co/functions/v1/live-worker" -H "apikey: sb_secret_আপনার_চাবি"
```

ম্যাচ না থাকলে উত্তর আসবে এমন: `{"ok":true,"skipped":"no match close",...}`। এর মানে সব ঠিক আছে।

**খ) সময়সূচি চলছে কি না দেখা।** SQL Editor-এ চালান:

```sql
select status, return_message, start_time
from cron.job_run_details
order by start_time desc
limit 5;
```

প্রতি মিনিটে একটা করে `succeeded` লাইন দেখা গেলে সময়সূচি কাজ করছে।

**গ) Worker-এর অবস্থা দেখা:**

```sql
select event, deadline, idle_until, updated_at from alert_state;
```

`event` এ বর্তমান গেমউইক নম্বর দেখা গেলে Worker FPL থেকে ডেটা পাচ্ছে।

## Worker কীভাবে কাজ করে (সংক্ষেপে)

- **সব সময়:** প্রতি মিনিটে সময়সূচি Worker-কে ডাকে। ম্যাচ কাছে না থাকলে Worker সঙ্গে সঙ্গে ফিরে যায়, তাই সপ্তাহের বেশিরভাগ সময় খরচ প্রায় শূন্য।
- **প্রতি ঘণ্টায়:** বর্তমান গেমউইক আর প্লেয়ারদের নাম আপডেট করে।
- **ডেডলাইনের পর:** প্রতি মিনিটে ৬০টা করে দলের প্লেয়ার তালিকা সংগ্রহ করে, যতক্ষণ না সবার দল আসে।
- **কিক-অফের ১০ মিনিট আগে থেকে ম্যাচ শেষ পর্যন্ত:**
  - প্রতি মিনিটে FPL-এর লাইভ ডেটা **একবার** পড়ে, সব ইউজারের জন্য।
  - আগের মিনিটের সঙ্গে মিলিয়ে বের করে কী বদলেছে: মাঠে নামা, গোল, অ্যাসিস্ট, পেনাল্টি সেভ বা মিস, কার্ড, আত্মঘাতী গোল।
  - প্রত্যেক ফোনে একটাই গোছানো নোটিফিকেশন পাঠায়।
- **ম্যাচ শেষ হলে:** ফুল টাইম স্কোর আর ইউজারের প্লেয়ারদের পয়েন্ট পাঠায়।
- **গেমউইকের প্রথম দেখায়:** কোনো নোটিফিকেশন পাঠায় না, শুধু অবস্থা মনে রাখে। এতে পুরনো খবর একসঙ্গে গিয়ে কাউকে বিরক্ত করে না।
- **অ্যাপ মুছে ফেললে:** যে ফোনে অ্যাপ নেই, Expo জানালে সেই ফোন তালিকা থেকে সরিয়ে দেয়।
